# زاجل CRM — نظام مبيعات الفريق

نفس تصميم وشاشات زاجل الأصلية (24 شاشة)، لكن على **سيرفر مشترك**: دخول حقيقي، صلاحيات يفرضها السيرفر،
بيانات ومكتبة معرفة ومرفقات مشتركة بين الموظفين، ونسخ احتياطي يومي، وواجهة API للربط مع أنظمة أخرى.

## الهيكل
| المسار | الوظيفة |
|---|---|
| `original/zajel-original.html` | النسخة الأصلية، **لا تُعدَّل أبداً** |
| `scripts/build.mjs` | تعديلات صغيرة وصريحة على الأصلية ← `public/index.html` (كل تعديل يجب أن ينطبق مرة واحدة وإلا يفشل البناء) |
| `src/worker.js` | السيرفر (Cloudflare Worker): دخول، مزامنة، ملفات، نسخ احتياطي، API |
| `src/permissions.js` · `src/phones.js` · `src/knowledge.js` | الصلاحيات · توحيد الهواتف وكشف التكرار · مكتبة المعرفة |
| `src/client/*` | طبقة المزامنة وتخزين مكتبة المعرفة في المتصفح |
| `src/static/_headers` | ترويسات الأمان |
| `migrations/` | جداول قاعدة البيانات (D1) |
| `docs/API.md` | توثيق الـ API للربط مع الأنظمة الأخرى |
| `PROJECT_BRIEF.md` | الملخص الوظيفي والقرارات (من صاحب المشروع) |
| `test/` | اختبارات: صلاحيات، هواتف، مكتبة المعرفة، أمان، متصفحات حقيقية، الشاشات الـ24 |

## تحديث الموقع المنشور (من جهازك)
`wrangler.jsonc` يشير إلى موقعك في حساب Cloudflare (**False Hardware**). كلمات السر الداخلية محفوظة هناك ولا تتأثر بالنشر.

أول مرة فقط (يلزم Node.js 20+ وGit):
```bash
git clone https://github.com/xnexgamerx-byte/Zajel_Sales
cd Zajel_Sales
git checkout claude/inspiring-ritchie-joroe9
npm install
npx wrangler login      # سجّل بالحساب الذي يملك False Hardware
```
كل تحديث بعدها:
```bash
git pull
npm install
npm run release
```
`npm run release` يطبّق تحديثات قاعدة البيانات ثم ينشر، بالترتيب الصحيح. استخدمه دائماً بدل `npm run deploy` وحده.

## تفعيل R2 (الملفات ومكتبة المعرفة والنسخ الاحتياطي)
1. لوحة Cloudflare ← False Hardware ← **R2 Object Storage** ← Enable (قد يطلب بطاقة؛ الحد المجاني 10GB).
2. `npx wrangler r2 bucket create zajel-files`
3. `npm run release` — لازم يظهر في آخر الأسطر `env.FILES (zajel-files)  R2 Bucket`.

## الأمان
- كلمات المرور: PBKDF2 على السيرفر، جلسات HttpOnly، ترويسات أمان (منع التضمين، HSTS…).
- **حماية من التخمين:** بعد 8 محاولات خاطئة لنفس المستخدم من نفس الجهاز يُمنع الدخول 15 دقيقة.
- **إنهاء الجلسات:** تغيير كلمة المرور يخرج الأجهزة الأخرى؛ وإعادة تعيين المدير لكلمة موظف يخرجه من كل مكان؛ وتعطيل الحساب يقطع وصوله فوراً.
- **كلمة المرور:** كل مستخدم يغيّر كلمته بنفسه بالضغط على بطاقة اسمه في الشريط العلوي (8 أحرف على الأقل).

## الصلاحيات (مفروضة من السيرفر)
المدير يحدد لكل موظف الشاشات والإجراءات من «الفريق والصلاحيات»، والسيرفر يطبقها (`src/permissions.js`):
- **القراءة:** الموظف بدون «الاطلاع على جميع التجار» يستلم تجاره ومتابعاتهم وأنشطتهم وعروضهم فقط. بيانات الشاشات غير المسموحة لا تُرسل له.
- **الكتابة:** تغيير المرحلة `changeStage`، الإسناد `assign`، اعتماد العروض/الحملات، القوالب، المكتبة، التسويق، الإعدادات — كلٌّ بصلاحيته. لا أحد غير المدير يعدّل الفريق أو ينشئ حسابات.
- **تكرار التاجر:** يُرفض أي رقم هاتف مسجل لتاجر آخر (بأي صيغة: `0770…` / `+964 770…` / أرقام عربية) حتى لو عند موظف لا يراه، ويذكر السيرفر اسم التاجر والموظف المسؤول.
- **سجل التدقيق:** الموظفون لا يعدّلونه ولا يحذفونه، ويُحتفظ بآخر 150 إجراءً.
- التعديل المرفوض يعود لقيمته مع رسالة بالسبب، ولا يوقف باقي التعديلات.

## مكتبة المعرفة المشتركة
- الكتب والأفكار والمسودات والحقائق على الخادم؛ نص الكتاب يُحمَّل عند الحاجة فقط ويُحفظ على شكل مقاطع من 50 صفحة؛ والمعالجة (PDF.js وOCR والقواعد) في متصفح من يرفع الملف، بدون ذكاء اصطناعي أو API مدفوع.
- **تشغيل مكتبة المعرفة الذكية:** رفع وتحليل وOCR وتعديل المسودات. **اعتماد رسائل المعرفة:** اعتماد/رفض فقط. **المدير:** حذف الكتب، الحقائق المعتمدة، التصدير والاستعادة.

## النسخ الاحتياطي
- **يومي تلقائي** (04:00 بغداد) إلى R2 في `backups/التاريخ.json`، ويُحتفظ بآخر 30 نسخة. لا يتضمن كلمات المرور؛ عند الاستعادة من نسخة JSON يعيّن المدير كلمات الموظفين.
- **تنزيل فوري (للمدير):** افتح `/api/backup` وأنت مسجّل دخول. القائمة: `/api/backups`. تشغيل نسخة الآن: `POST /api/backups/run`.
- **استعادة قاعدة البيانات لنقطة زمنية** (D1 Time Travel، تلقائي ومجاني): `npx wrangler d1 time-travel restore zajel-trial --timestamp=<وقت>`.
- زر «تنزيل نسخة JSON» في الإعدادات ما زال متاحاً.

## زر «مسح جميع بيانات الشركة» (المدير فقط)
يحذف التجار والأنشطة والمتابعات والعروض والحملات والتصعيدات وسجل التدقيق لدى الجميع. **يبقى** الفريق والقوالب والمكتبة والإعدادات. لا يمكن التراجع عنه من الواجهة (استخدم النسخ الاحتياطي).

## ملاحظات
- أسماء `zajel-sales-trial` و`zajel-trial` أسماء تقنية قديمة (للـ Worker والقاعدة) لا يراها الموظفون؛ تظهر فقط في عنوان الموقع. لتغييرها: Worker جديد بنفس القاعدة + `wrangler secret put SESSION_SECRET`، أو ربط نطاق خاص بالشركة من لوحة Cloudflare.
- الخط (Google Fonts) ومكتبتا PDF.js وTesseract تُحمَّل من الإنترنت.
- كل شركة جديدة = نشر منفصل بقاعدتها وملفاتها.

## محدوديات معروفة
1. مكتبة المعرفة: تحديثات الزملاء تظهر عند فتح الشاشة أو بعد 15 ثانية من آخر تحميل. ملف PDF الأصلي يُحفظ حتى 100MB (حد Cloudflare)؛ الأكبر يُقبل نصه لكن OCR للصفحات اللاحقة يتطلب إعادة اختيار الملف.
2. التعديل المتزامن لنفس العنصر: آخر حفظ يفوز (عناصر مختلفة لا تتعارض).
3. الملفات المرفوعة تُنزَّل لأي مستخدم مسجّل يعرف معرّفها (معرّف عشوائي 128-bit).
4. أرقام وبيانات الحملات التسويقية التجريبية والتحذيرات التي كتبها صاحب المشروع (مثل تحذير تسعير العروض) تركتها كما هي.
