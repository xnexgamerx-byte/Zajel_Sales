# زاجل CRM — نسخة الفريق

نفس تصميم وشاشات النسخة الأصلية بدون أي تغيير، لكن البيانات الآن على **سيرفر مشترك** بدل متصفح كل مستخدم.

## الهيكل
| المسار | الوظيفة |
|---|---|
| `original/zajel-original.html` | النسخة الأصلية. **لا تُعدَّل أبداً** |
| `scripts/build.mjs` | تعديلات محددة على الأصلية → `public/index.html` (كل تعديل واضح ومراجَع) |
| `src/client/zajel-sync.js` | طبقة المزامنة في المتصفح |
| `src/worker.js` | السيرفر: دخول، مزامنة، ملفات، API للربط |
| `migrations/` | جداول قاعدة البيانات (D1) |
| `PROJECT_BRIEF.md` | ملخص المشروع الوظيفي والقرارات (من صاحب المشروع) |
| `docs/API.md` | توثيق الـ API للربط مع نظام الشركات |
| `test/e2e.cjs` | اختبار متصفحين حقيقيين (مدير + موظفة) |
| `test/screens.cjs` | فتح الشاشات الـ24 والتأكد من عدم وجود أخطاء JavaScript |

## التشغيل محلياً
```bash
npm install
npm run db:init
npm run dev          # http://localhost:8787  (المدير: manager / كلمة المرور من .dev.vars)
npm test             # يحتاج السيرفر شغال
```

## النشر على Cloudflare (مرة واحدة)
```bash
npx wrangler login
npx wrangler d1 create zajel            # انسخ database_id إلى wrangler.jsonc
npx wrangler r2 bucket create zajel-files
npm run db:init:remote
npx wrangler secret put SESSION_SECRET   # نص عشوائي طويل (32+ حرف)
npx wrangler secret put ADMIN_PASSWORD   # كلمة مرور حساب manager الأول
npx wrangler secret put INTEGRATION_API_KEY   # مفتاح ربط النظام الخارجي (اختياري)
npm run deploy
```
بعد أول دخول للمدير تُنشر القوالب والمحتوى الأساسي للجميع (بدون العملاء التجريبيين). كل شركة جديدة = نشر منفصل بقاعدتها وملفاتها.

## ما تغيّر عن الأصل (ملخص)
- الحفظ: من `localStorage` إلى السيرفر، مع مزامنة كل ~8 ثوانٍ، وكل عنصر (عميل/مهمة/…) يُحفظ لوحده فلا يطغى تعديل موظف على آخر.
- الدخول: حقيقي (كلمات المرور مشفّرة PBKDF2 على السيرفر، جلسة HttpOnly)، والجلسة تبقى بعد تحديث الصفحة.
- الملفات المرفوعة (المكتبة/التسجيلات): في R2 بدل IndexedDB.
- حُذفت ملاحظات "نسخة تجريبية/هذا المتصفح" لأنها صارت غير صحيحة، وكُتب تحذير على زر حذف/استبدال البيانات.

## محدوديات معروفة (المراحل القادمة)
1. **مكتبة المعرفة (Zajel Knowledge / PDF + OCR)** ما تزال محلية في متصفح كل مستخدم. المرحلة 2.
2. **الصلاحيات الدقيقة (views/actions)** تُفرض بالواجهة. السيرفر يفرض فقط: غير المدير لا يكتب `reps` ولا ينشئ حسابات. المرحلة 3.
3. التعديل المتزامن لنفس العنصر: آخر حفظ يفوز (تعديل عميلين مختلفين لا يتعارض).
4. بقيت عبارات "تجريبي" في رسائل ثانوية (مثل حد استيراد 500 سطر ورسائل في مكتبة المعرفة).
